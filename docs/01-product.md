# 01-product - WHY

## 목표

팀 업무를 시각화한다. **'지금 누가 뭐 해?'** 라는 질문이 사라지게 하는 것이 목표다.

## 페르소나

10명 규모 스타트업의 팀리더 (30~40대)

## MVP 범위

- **CRUD 4종 모두 화면에서** - 추가 / 목록 / 수정 / 삭제
- **상태 분류 + 마감 시각(`due_at`) 지정·표시**
  - 날짜만이 아니라 시간까지 지정한다. 예) `2026-12-31 18:00`
- **라이트/다크 테마 토글** (localStorage)
- **모바일 반응형** (360px)

## UI 톤

Mac OS 스타일 - 둥근 모서리, 부드러운 그림자, 반투명 카드, 시스템 폰트

## 확장 (MVP 이후)

JWT 로그인, 팀, Kanban, 채팅, CI/CD

## 범위 외

외부결제, 네이티브앱, WebRTC, 외부캘린더, 파일업로드
WebSocket - MVP 는 폴링으로 한다. 확장 단계로 보류.

## 성공 기준 (실습에서 눈으로 확인 가능한 것만)

| 기준 | 확인 방법 |
|---|---|
| 새로고침해도 데이터 유지 | 브라우저 새로고침 후 목록 그대로 |
| 360px 에서 안 깨짐 | 개발자도구 폭 360px |
| CRUD 4종 화면 동작 | 추가·목록·수정·삭제를 화면에서 수행 |
| 테마 토글 작동 | 토글 후 새로고침해도 유지 |
